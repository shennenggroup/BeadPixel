使用说明

1. 上传图片

拖拽或点击上传区域，选择一张图片（支持 JPG、PNG、WebP 格式）。

2. 调整参数

  • 网格尺寸：最终拼豆数量（如 64×64 = 4096 颗），生成结果严格等于该网格
  • 拼豆规格：5mm 标准豆 / 2.6mm 迷你豆，影响图纸上的实际尺寸
  • 颜色数量：最多使用多少种真实拼豆颜色（自动 = 按覆盖率智能选择）
  • 抖动：轻度抖动让渐变更自然且不产生噪点；标准抖动渐变最强
  • 适应方式：保持比例留白 / 自动裁剪填满 / 拉伸
  • 细节优先：保护轮廓、五官、文字等高对比区域
  • 拼豆品牌：Perler / Artkal / Hama 真实色板

3. 生成拼豆图

点击"生成拼豆图"，算法会对每个格子做智能采样（区域平均 + 中心加权 + 主导色 + 边缘保护），再从真实拼豆色板中选择最接近的颜色。

4. 四种视图模式

  • 拼豆模式：真实拼豆视觉（圆豆、孔、高光、阴影）
  • 图片模式：纯色像素图
  • 网格模式：网格线 + 每 10 格参考线
  • 编号模式：每格显示颜色编号（放大后可读）

5. 导出结果

  • PNG：拼豆/像素风格图片（可在「显示编号」中叠加每格颜色编号）
  • PDF：可制作的拼豆图纸（编号 + 颜色清单 + 数量）
  • CSV：颜色清单和图纸网格数据

6. 画笔修改细节

生成后点击 ✏️ 画笔修改，从带编号的调色板选一种颜色，再在小图上点选或拖拽即可改色。每种颜色都有编号（与右侧「颜色统计」一致），方便区分。修改会自动保存并同步到导出的 PNG / PDF / CSV。

7. 历史记录

每次生成都会自动保留在🕘 历史记录中（缩略图 + 参数 + 时间）。可加载回到预览/导出、重命名或删除（删除会同时清理对应文件）。
